# 🤖 AI Learning Buddy

An AI-powered learning companion designed to make learning more interactive, personalized, and accessible for students.

## 📌 About the Project

**AI Learning Buddy** is a Generative AI-based educational assistant developed as part of the **AI EmpowHer Program by Infosys Springboard**.

The project aims to help students learn effectively by providing AI-powered assistance, simplified explanations, and interactive responses to their learning-related questions.

## 🎯 Objectives

* Make learning interactive and engaging
* Provide instant AI-powered learning assistance
* Simplify complex concepts
* Support self-paced learning
* Encourage students to explore topics through interactive conversations
* Demonstrate the application of Generative AI in education

## ✨ Features

* 🤖 AI-powered learning assistance

## ⚙️ How It Works

```text
User
  ↓
Learning Question / Prompt
  ↓
AI Learning Buddy
  ↓
Gemini API
  ↓
AI Processing
  ↓
AI-Generated Response
  ↓
User
```

The user provides a learning-related question or prompt. The AI Learning Buddy processes the input using a Generative AI model and provides a relevant response to support the user's learning.

## 🚀 Getting Started

### Prerequisites

* Python 3.x
* Google Colab
* Google account
* Gemini API key

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/AI-Learning-Buddy.git
```

Navigate to the project directory:

```bash
cd AI-Learning-Buddy
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

### 🔑 API Key Configuration

Obtain a Gemini API key from Google AI Studio.

For security reasons, do not hard-code your API key or upload it to GitHub.

Example:

```python
import os

API_KEY = os.getenv("GEMINI_API_KEY")
```

Configure your API key securely before running the project.

## ▶️ Running the Project

1. Open the project notebook in Google Colab.
2. Connect to a runtime.
3. Install the required dependencies.
4. Configure the Gemini API key securely.
5. Run the notebook cells sequentially.
6. Start interacting with the AI Learning Buddy.
